# 🚀 Invoicely - Modern Invoice Generator

Invoicely is a sleek, modern, and highly efficient invoice generator built with **React**, **Tailwind CSS**, and **@react-pdf/renderer**. It allows users to create professional invoices with a live preview and download them as clean, high-quality PDFs.

Developed with ❤️ by **Usman**.

---

## ✨ Features

- **🎨 Modern Design**: A clean, minimalist UI built with Tailwind CSS v4.
- **⚡ Live Preview**: Real-time updates as you fill in the invoice details.
- **📄 Professional PDFs**: Generate and download clean, professional A4 invoices instantly.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile screens.
- **🏗️ Dynamic Line Items**: Easily add, edit, or remove items with automatic tax and total calculations.
- **📅 Smart Defaults**: Pre-filled with current date and 30-day due date for speed.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **PDF Generation**: [@react-pdf/renderer](https://react-pdf.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Date Utilities**: [date-fns](https://date-fns.org/)

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

1. **Clone the repository** (or copy the files):
   ```bash
   # Navigate to the project directory
   cd "New folder (2)"
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
